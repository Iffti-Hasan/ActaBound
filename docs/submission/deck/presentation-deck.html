The Problem Statement

The Fatal Vulnerability of Naive AI Wallets

1. Prompt Injection (OWASP LLM01)
Adversarial instructions hidden in transaction metadata or chat prompts hijack the LLM to transfer user assets to an attacker's address.
Critical Vulnerability
2. IEEE 754 Floating-Point Drift
JavaScript floats (0.1 + 0.2 = 0.30000000000000004) create micro-rounding gaps in balance calculations, enabling silent drainage.
Accounting Risk
3. TOCTOU & Direct Key Access
Time-of-Check to Time-of-Use tampering where calldata changes post-approval, or the LLM memory leaks private key bytes directly.
Zero Trust Violation
The Verdict: Autonomous AI agents must never hold direct signing keys or possess unconstrained on-chain authority.
Failure Modes Analysis Security & Compliance: 30% Weight
